# Task-Manager

## About the Project
Task Manager is a Java Swing GUI application developed as a final project for a Java programming course offered by B Programmer. The project was built to apply the Java concepts and programming skills learned throughout the course.

## Features
- User login interface.
- Create and manage tasks.
- Assign priority levels to tasks.
- Set deadlines and receive deadline alerts.
- Mark tasks as completed.
- Filter tasks by completion status.
- Color-coded task priorities.
- View task statistics.
- Delete individual tasks or all completed tasks.

## Technologies Used
- Java
- Java Swing (GUI)
- Object-Oriented Programming (OOP)
- ArrayList
- Event Handling
- Inheritance

## Purpose
This project demonstrates the practical application of Java programming concepts through the development of a graphical task management application.
